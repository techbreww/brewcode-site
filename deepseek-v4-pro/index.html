Why BrewCode

Three things that matter.

01

Truly open. Any model. No lock-in.

Switch between Anthropic, OpenAI, Gemini, Ollama, LM Studio, DeepSeek — over 200 models — with one command. A per-repo profile pins your settings so every clone boots the same agent. No vendor lock-in, no migration headaches.

02

Verified private. Build fails if it phones home.

Every release is mechanically scanned before shipping. If a single telemetry endpoint, metrics call, or fingerprint shows up in the bundle, the build fails. Your prompts and code go only to the model provider you choose.

03

Works offline. Local models, zero network.

Point BrewCode at Ollama or LM Studio and code with local models — no API keys, no internet. Your code never leaves your machine. Runs on macOS, Linux, Windows, and even Android via Termux.

How it works

Brew, step by step.

Not a chatbot wrapper. Not another IDE plugin. A real agent loop that reads your codebase, runs real tools, and streams every change live.

1

Connect any model

Set a provider once and BrewCode speaks their protocol natively. Switch anytime with /provider. Lock in defaults per repo with a profile file.

2

Give it real work

Reads and writes files, runs shell commands, searches with ripgrep, browses documentation, and spawns subagents — all streamed token-by-token in your terminal.

3

Extend anything

MCP servers, custom skills, hooks, 150+ slash commands, scheduled tasks, swarms, and workflows. A gRPC server lets your own tooling drive BrewCode.

Privacy

Verified zero telemetry.

Every release is mechanically scanned before shipping. A dedicated privacy verification step checks the entire output bundle for telemetry endpoints, metrics calls, environment fingerprinting, and feedback back-channels.

If any pattern is detected, the build fails. No silent data collection. No opt-out dark patterns. Nothing to trust — you can verify it yourself.

  • No telemetry or usage metrics endpoints
  • No environment or infrastructure fingerprinting
  • No feedback back-channels
  • Local models via Ollama or LM Studio never leave your machine

Your code and prompts go only to the model provider you choose. Nothing calls home.
