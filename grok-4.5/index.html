Capabilities

Built for serious work in real repositories

brewcode is an agent with tools, permissions, and a streaming TUI — designed so you can trust what it does on your machine.

01

Tools that touch the repo

Read and edit files, run shell commands, search with ripgrep, browse the web, and spawn subagents. Output streams live into a fast React-powered TUI with themes, vim bindings, and a statusline.

02

Sandboxed. Permissioned. Reviewable.

Bash runs inside a sandbox with a per-tool permission system. Plan mode, git worktrees, and token-by-token diffs make every change something you can inspect before it lands.

03

Profiles that travel with the repo

Drop a .brewcode-profile.json to pin model, base URL, and runtime defaults. Every clone boots the same agent configuration.

04

Extensible end to end

MCP servers, skills, hooks, 150+ slash commands, scheduled tasks, swarms, and workflows — plus a gRPC server and editor modes for your own tooling.

Privacy

Verified no phone-home

Every release build is mechanically scanned before it ships. If a telemetry endpoint, metrics call, or infrastructure fingerprint shows up in the bundle, the build fails.

  • No telemetry or usage metrics endpoints
  • No environment or infra fingerprinting
  • No feedback back-channels
  • Local models via Ollama or LM Studio never leave your machine

Your code and prompts go only to the model provider you choose. Nothing calls home.
